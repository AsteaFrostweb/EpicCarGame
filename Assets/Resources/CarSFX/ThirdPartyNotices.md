# Car SFX Prototype Sources

These placeholder/prototype vehicle sounds are from OpenGameArt and are listed there as CC0.

- `loop_0.wav` through `loop_5.wav`: "racing car engine sound loops" by domasx2, CC0, https://opengameart.org/content/racing-car-engine-sound-loops
- `generic_car_startengine.wav` and `generic_car_startengine_1.wav`: "Car engine start 01" by looneybits, CC0, https://opengameart.org/content/car-engine-start-01
- `engine_start_up_01.wav`: "Car engine Start Up 02" by looneybits, CC0, https://opengameart.org/content/car-engine-start-up-02
- `car1.wav`: "Car 1" by Yaroslav_Novikov, CC0, https://opengameart.org/content/car-1-1

Attribution is not required for CC0, but these links are kept so the source and license are traceable.
